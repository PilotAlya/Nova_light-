# Как открыть рабочую таблицу

Файл: [Nova_2.0_салон.xlsx](Nova_2.0_салон.xlsx)

1. Залей на Google Диск.
2. Правый клик → **Открыть с помощью → Google Таблицы**.
3. **Файл → Сохранить как Google Таблицу.**

## Листы

| Лист | Откуда | Что делать |
|------|--------|------------|
| Главная | Nova 2.0 дашборд | Смотреть цифры, не править формулы |
| Фурнитура | склад + коды Инфо | Основной ввод товара |
| Продажи | модуль продаж | Строка на чек |
| Заказы | Л-ки CRM | Клиент, размер, статус |
| Калькулятор + Цены_Лки | как `19_08_Raschet_L-ka` | Три блока: ЛДСП / ДВП / кромка. Размеры в **мм**. Прайс меняешь на Цены_Лки |
| Заявки_* | QUERY с Фурнитуры | Не заполнять, если пусто — `;` заменить на `,` |
| Задачи | чеклист + Инфо | да/нет |
| Касса | салон, один ящик | колонка «должно быть» |
| Грузчики | тетрадь | сумма и подпись |
| Шпаргалки | база знаний приложения | Инфо и вопросы клиенту |
| Аналитика | неделя выручки | формулы |

Примеры на Фурнитуре помечены «пример» — замени на свои коды из Инфо.

На Фурнитуре колонка Поставщик: список с листа **Поставщики**.
