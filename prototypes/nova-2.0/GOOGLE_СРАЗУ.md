# Сразу Google Таблица (не Excel)

Я не могу создать файл на **твоём** Google Диске — нет доступа к аккаунту.

Ты собираешь таблицу за 2 минуты, и она сразу с флажками:

1. Открой [Google Таблицы](https://sheets.google.com) → **Создать** → пустая таблица.
2. **Расширения → Apps Script**.
3. Сотри текст в редакторе, вставь весь файл `setupRelanSalon.gs` из этой папки.
4. Диск → Сохранить. Сверху выбери функцию **setupRelanSalon** → **Выполнить**.
5. Разреши доступ своему Google (один раз).
6. Вернись на таблицу, обнови страницу (F5).

Готово: листы салона, калькулятор с **флажками**, заявки, касса. Ссылка на таблицу — кнопка «Настройки доступа» справа вверху.

Если Google ругается на формулы — напиши, поправим разделитель `,` / `;`.
