# Что мы делаем сейчас

Собираем **приложение Nova 2.0** (светлое). Google/Excel больше не используем.

Данные хранятся в SQLite: `backend/data/nova.db` (таблицы `work_*`). После перезагрузки страницы и сервера они остаются.

Запуск:

```
cd backend && npm run dev
npm run dev
```

Открыть http://localhost:5180/

Портфолио-демо не ломаем: `npm run dev:demo`. Старый тёмный дашборд: `npm run dev:v2`.
