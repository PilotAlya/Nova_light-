| Документ | Файл в репо | Живая копия |
|---|---|---|
| Ход работы (шаги проекта) | [ХОД_РАБОТЫ.md](ХОД_РАБОТЫ.md) | Google Таблица на твоём аккаунте |
| Рабочий контур салона | папка [sheets/](sheets/) | другая Google Таблица на твоём аккаунте |

Принцип: не красиво, а помогает здесь и сейчас. Старая тёмная Nova (`src/NovaDashboard.demo.tsx`) — портфолио, не меняем. Светлое приложение **не начинаем**, пока салонная таблица не пройдёт 1–5 рабочих дней.

`Nova_2.0_прототип.xlsx` — запасная копия структуры. Работать нужно в Google Sheets, не в этом xlsx.

## Как создать таблицу салона (5 минут)

1. Google Drive → **Создать → Google Таблица**. Название: `Nova 2.0 — салон`.
2. Для каждого CSV из `sheets/` : **Файл → Импорт → Загрузка** → вставить как **новый лист** (не «заменить таблицу» после первого файла).
3. Порядок листов: Сегодня, Касса, Грузчики, Склад_розница, Заявки, О_прототипе.
4. На листе **Заявки** переименуй `ПОСТАВЩИК_1/2/3` в реальных.
5. Ссылку на таблицу можно вписать в [ХОД_РАБОТЫ.md](ХОД_РАБОТЫ.md) (ячейка «Результат» у шага 3).

Листы:

- **Сегодня** — обязательные дела открытия/кассы/сверки
- **Касса** — наличка, приход, расход прочее, сверка с программой
- **Грузчики** — заказ, сумма, подпись (как тетрадь)
- **Склад_розница** — код/название как в Инфо, факт vs программа, последний привоз
- **Заявки** — 3 колонки-поставщика: название+код + сколько заказать (ориентир: Инфо → Отчёты → Количественно-сумовой, галочка «Розница»)

Л-ки и Wiki в этот файл не входят — отдельные этапы в ходе работы.

## Как создать таблицу хода работы

1. Создать Google Таблицу `Nova 2.0 — ход работы`.
2. Скопировать таблицу из [ХОД_РАБОТЫ.md](ХОД_РАБОТЫ.md) (заголовки + строки).
3. Вставить ссылку обратно в верх [ХОД_РАБОТЫ.md](ХОД_РАБОТЫ.md).

Цифры кассы и остатков в git не коммитить.
