# Заявки: один список → склад → три заявки

Пишешь только на листе **Фурнитура**. Остальное считается само.

## Лист «Поставщики»

В столбец A:

```
Рондо / Ладья
Партнер
Васильево / Ортус
```

На листе **Фурнитура** колонка C — выпадающий список из этих трёх строк (Данные → Проверка данных → список из диапазона `Поставщики!A:A`).

## Лист «Фурнитура» (ты заполняешь)

| Код (Инфо) | Название как в программе | Поставщик | Остаток факт | Остаток в программе | Последний привоз (кол-во) | Заказать сейчас |
|---|---|---|---|---|---|---|

- Одна позиция = одна строка. Код тот же, что в Инфопредприятии.
- «Заказать сейчас» — сколько кладёшь в заявку. Ориентир: Инфо → Отчёты → Количественно-сумовой → галочка **Розница** (сколько привозили в последний раз).
- Если товар закончился — добавляешь строку сюда. Это сразу попадает на склад (это и есть склад).

Не дублируй один и тот же код второй строкой — поправь количество в уже существующей.

## Лист «Заявка_Рондо» (формула в A1)

Русская Google Таблица (точка с запятой):

```
=QUERY(Фурнитура!A:G;"select A,B,F,G where C = 'Рондо / Ладья' and G > 0";1)
```

Английская (запятая):

```
=QUERY(Фурнитура!A:G,"select A,B,F,G where C = 'Рондо / Ладья' and G > 0",1)
```

На печать/отправку поставщику остаются: код, название, последний привоз, сколько заказать.

## Лист «Заявка_Партнер» (формула в A1)

```
=QUERY(Фурнитура!A:G;"select A,B,F,G where C = 'Партнер' and G > 0";1)
```

## Лист «Заявка_Васильево» (формула в A1)

```
=QUERY(Фурнитура!A:G;"select A,B,F,G where C = 'Васильево / Ортус' and G > 0";1)
```

Если формула ругается на `;` — замени на `,` (зависит от языка таблицы).

## Что не делать

- Не вести склад отдельным ручным списком «как в заявках».
- Не писать Ладья и Рондо как двух разных поставщиков — это одна группа.
- Не писать Ортус отдельно от Васильево.
